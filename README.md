# Getting Back to Tri

Personal Progressive Web App for rehab, strength, mobility and swim/bike/run training logging.

Current release: **v1.2 PWA**.

## GitHub Pages
Publish from the `main` branch and `/(root)` folder.

## Files
Keep these five files at the repository root:
- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `icon.svg`
- `README.md`

Training history is stored locally in the browser/PWA. Export CSV backups periodically.

## v1.2
Adds a guided Daily Quick Routine with 12 automatic 30-second intervals (6:00 total timed work).
