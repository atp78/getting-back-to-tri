Complete local backup

The complete backup still contains everything together so it can restore the whole app. It is separate from the two-file cloud-sync structure.

Google Drive setup

My Drive › Getting Back to Tri

The folder now contains two active sync files: Workout Library for reusable session definitions, and Personal Data for completed sessions, recovery data, settings and your weekly plan. OAuth access tokens remain in memory only.

Google Cloud setup
  1. Enable the Google Drive API in your Google Cloud project.
  2. Use an OAuth 2.0 Client ID for a Web application.
  3. Authorised JavaScript origin: https://atp78.github.io.
  4. While the OAuth app is in Testing, add the Google accounts you use as test users.
